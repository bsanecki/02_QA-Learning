# Appium Android Basics

Automated Android UI testing using Python, Pytest, Appium, and UiAutomator2.

## Scope

- Android device connectivity
- Settings screen navigation
- Settings categories and search
- Device information and system properties
- Battery status and screen orientation

## Tech Stack

- Python
- Pytest
- Appium
- UiAutomator2
- Android Debug Bridge (ADB)

## Run Tests

Start the Appium server:

```bash
appium
```

Run the test suite:

```bash
python -m pytest -v
```

A practical mobile test automation project developed as part of my QA Automation portfolio.
