# Jira

A collection of Jira exercises and practice work created while learning how Jira is used in QA and software development workflows.

The repository documents my practice with managing tasks, reporting bugs and working with issues throughout the software testing process.

## Contents

- **Exercises** — Jira practice tasks and scenarios
- **Projects** — practice projects and workflows
- **Bug Reports** — example bug reports created in Jira
- **JQL** — Jira Query Language exercises
- **Notes** — Jira-related notes and useful information

## Goal

The goal of this section is to develop practical Jira skills and become comfortable using Jira as part of a QA testing workflow.
